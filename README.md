# LeetCode Solutions

My solutions to [LeetCode](https://leetcode.com/) problems, written in C#, C++ and Go while practicing data structures and algorithms.

## Structure

| Folder | Language |
|--------|----------|
| [C#/](C%23/) | C# |
| [C++/](C%2B%2B/) | C++ |
| [Go/](Go/) | Go |

Each file holds one solution, and some problems are solved in more than one language.

## File header

Every solution starts with its time complexity, space complexity and LeetCode problem number:

```cpp
// Time: O(n)
// Space: O(1)
// Problem No: 2553
```

Files without a problem number are practice exercises from other sources.

## Finding a solution

Search by LeetCode problem number:

```bash
grep -rlw "Problem No: 217" C# C++ Go
```
